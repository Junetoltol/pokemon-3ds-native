# Ultra Sun local execution — 2026-11-09

The user supplied CIA/CCI files and requested proceeding with available inputs. Ultra Sun replaces Y as the first retail-input experiment for this session. Y remains untested.

## Input inspection and implementation

- Used the supplied NCSD CCI directly. First executable NCCH reports program ID `00040000001B5000`, product `CTR-P-A2AA`, and the no-encryption flag. Actual executable/module analysis succeeded; the filename alone was not treated as proof.
- Full-file SHA-256 and input size recorded privately. Retail region, game revision and patch version are not independently certified. Runtime output `v2` is not being reported as a Pokémon update version.
- `3dsrecomp analyze`: main executable + 132 modules, 83,271 functions, 93.2% code discovery reported. This is static discovery coverage, not correctness or performance coverage.
- Extended the conversion driver with explicit Y/Ultra Sun profile IDs and encrypted-header rejection. An Ultra Sun dump cannot be relabelled as Y. Added bounded real-port execution and a local-only macOS app packager.
- All game inputs, translated C, static archives, executables, app bundles, runtime data and raw logs remain under ignored local paths. No CIA conversion was attempted. Ultra Moon and Super Mystery Dungeon were not executed.

## Build verified

- Reused pinned upstream sources from the initial project audit.
- Generated 708 files / approximately 751 MiB C, compiled 574 translation units, and linked `pokemon-ultra-sun-local` with Zakuro.
- Full conversion/build completed with exit status 0 in 719.12 seconds. The resulting executable is 263,400,528 bytes and is Mach-O ARM64.
- Linker warned about reducing `__DATA,__common` section alignment from `0x8000` to `0x4000`. Runtime smoke tests below passed; this warning is retained for follow-up rather than treated as resolved.
- Disk space was limited. Verified that all 574 intermediate object files were archived before removing those rebuildable files. Compressed each generated `.c` with a decompression SHA-256 check before removing its raw copy. The static archive and generated sources remain available locally; original game files were not modified. Sources can be restored from `.c.gz` if needed.
- Generated executable is hardlinked into its private port directory to avoid another full copy. The private `.app` uses an APFS clone and ad-hoc signing. It references the original CCI, which must remain at its current path. It is not a redistributable game package.

## Execution verified

- Interpreter-only baseline: completed 5 initial frames; 0 draws. This is separate from the recompiled test.
- Actual local port, headless: completed 120 requested frames, exit status 0, 1,095 draw calls. Log explicitly reports `running the recompiled code linked in`, 194,733 entry points and 132 modules. Initial slice reported 0.33% interpreted instructions. This ratio applies only to that initial slice.
- GUI log: OpenGL 4.1 Metal on Apple M4; software PICA/3D rasterization requested. OpenGL presentation does not imply the guest 3D renderer is GPU accelerated.
- Visually observed the real Ultra Sun language-selection screen, including rendered upper/lower screens and English/Spanish/French/German options. No language was confirmed. The private app was left open at that screen.
- Audio was muted. Runtime data is isolated under `private/runtime-data/ultra-sun`; the game initialized its own new save/extdata directories. This is not a save/load or save integrity test.
- CTest runtime, local-tools and mock-launcher checks passed after tooling changes. These do not certify retail gameplay.
